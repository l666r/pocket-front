# PocketRoute — Frontend

Next-generation AI-powered spatial travel planner and intelligent routing assistant.

## Features
- 🤖 **PocketRoute AI Assistant**: ChatGPT/Gemini-style dynamic travel companion.
- 🗺️ **Plan the Trip**: Budget, traffic, weather, and time-aware itinerary generator.
- 🔄 **Re-Arrange your Trip**: Interactive stop reordering, cancellation, and live cost calculation.
- ⭐ **My Favorites**: Starred curated travel itineraries.
- 📍 **Contribute Places**: Google Maps Local Guides-style community crowdsourcing with upvotes.
- 🔗 **Standalone Shared View**: Direct link sharing (`#/share/trip/:code`).
- 💡 **User Suggestion Portal**: Real-time feedback collection saved to MongoDB Atlas.

## Getting Started
```bash
npm install
npm run dev
```
Runs on `http://localhost:3000`.
